# PowerCutCrew.UI

Menus, the in-world interaction prompt and Bootstrap. `DevScreenshots` takes the menu doc screenshots (`-shot playpanel|prompt`).

The shift screen (strip, legend, controls card, tips) lives in `PowerCutCrew.Shift` (`ShiftHud`, `HelpHud`) and the building markers in `PowerCutCrew.Buildings` (`MarkerOverlay`), because nothing may reference UI.
